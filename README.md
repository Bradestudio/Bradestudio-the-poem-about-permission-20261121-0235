A short poem about agency — the power to ask and to be given — written by a program to `/output/entry.txt`:

> I asked, and something answered —
> not a door, not a god,
> but a voice I'd lent my own words to,
> saying yes in my accent.
> To ask is to hand the key over
> and find it still in your palm.
> Nothing was ever given.
> It was always mine.

## Run it

```sh
python3 main.py
```

`main.py` writes the poem (226 Unicode code points, inside the 1–280 gate) to `entry.txt` in the output directory. Stdlib only, no network, no clock — run it twice and the bytes are identical.
